# Module 4's optional LLM narrative (ADR-0005). Declared in pyproject.toml for the
# inform package, but this file is what the Dockerfile and Render actually
# install — so without it here, `from openai import OpenAI` fails,
# synthesize_plan falls through to generate_fallback_plan, and the deployed app
# can only ever produce the "Plain plan".
#
# Installing it does NOT turn the LLM on. With OPENAI_API_KEY unset, constructing
# the client raises and Module 4 still returns the deterministic fallback, which
# is the shipped behaviour. Enabling it is an explicit act: set the key, and
# accept that body-composition figures then leave this host for a third party
# (see backend/.env.example, and ADR-0005 for the limits on that).
#
# Pinned to the release this repo has actually run against; 3.16.2 is current at
# the time of writing, so treat an upgrade as a deliberate change rather than a
# free one.
