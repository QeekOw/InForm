# Confirm Segmental Readings Before Imbalance Recommendations

**Status:** Accepted
**Date:** 2026-09-18

OCR can silently misread segmental lean values, and the resulting bilateral deviation can still cross the existing 5% threshold. Module 3 therefore assesses each arm or leg pair only after both readings have been confirmed or corrected by the person; a correction counts as confirmation and prompts them to check the source sheet. Unconfirmed pairs are omitted independently, with the rest of the plan still available and the skipped check made explicit, avoiding both unsupported claims and a full-plan block.
